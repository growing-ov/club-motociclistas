Como esta construido el proyecto MongoDB

El club no usa joins: cada documento apunta a otro guardando su ObjectId en texto plano. Los JSON Schemas describen el contrato de datos de cada coleccion y validan lo que se devuelve por la API.

Django 6.1 django-mongodb-backend JSON Schema 2020-12 jsonschema Docker Gunicorn WhiteNoise
